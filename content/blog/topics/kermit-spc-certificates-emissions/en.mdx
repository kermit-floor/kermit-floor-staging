A flooring document is useful when it answers a particular question about the product being supplied. A technical data sheet helps define a specification; an emissions report addresses the tested sample and method; a certification adds the scope and oversight of its scheme. These documents should be read together, with the product code and intended use beside them.

For a Kermit project, begin with the selected collection, decor, thickness, wear layer and backing. Then identify what the client or project specification actually asks you to demonstrate. This prevents a folder of impressive-looking logos from obscuring a missing product detail.

## Four document types, four different jobs

| Document | What to read first | What it does not establish by itself |
| --- | --- | --- |
| Manufacturer technical data sheet | Product configuration, properties, units, methods and revision | Independent certification of every stated property |
| Laboratory test report | Sample identity, method, conditions, result and report number | Coverage of other products or every future batch |
| Product certification | Scheme, holder, covered product range, status and conditions | Approval for uses outside its stated scope |
| Management-system certificate | Organization, sites, activities, standard and validity | A specific plank's emissions, acoustics or fire result |

Keep a file name as an index, not as your conclusion. Open the document and read the product description and any annex. Where a reference is unclear, ask the supplier for the mapping between the ordered code and the covered product family, then verify the certification status with the issuer when relevant.

ISO 9001 concerns a quality management system. It is not a flooring emissions test. ISO also explains that external certification bodies issue certificates; ISO itself does not certify companies. Use the actual standard, issuer and scope written on the document. See [ISO's quality-management overview](https://www.iso.org/standards/popular/iso-9000-family) and [certification explanation](https://www.iso.org/certification.html).

## What FloorScore tells you

[FloorScore](https://www.scsglobalservices.com/services/floorscore) is a certification program addressing VOC emissions from covered products. Check the current SCS listing and certificate scope for the product offered. An emissions certification should not be translated into “chemical-free,” “zero emissions” or a blanket health claim.

For private-label products, SCS describes a separate assessment for use of the FloorScore name and logo. A manufacturer's certificate is therefore not, by itself, permission to add the mark to a buyer's packaging. Settle the branding and covered-product question before approving artwork.

## Read emissions evidence precisely

Emissions describe substances released under specified test conditions. Ingredient information describes composition. They answer different questions. A claim about the content of one substance does not establish a complete emissions profile, and a result for one measured compound does not answer a request covering several compounds.

When reviewing a report, record:

- The exact sample or product-family description, including backing where relevant.
- The laboratory and report identifier, issue date and test method.
- The units, measurement conditions and the criterion used to judge the result.
- Any limitations, exclusions or referenced annexes.
- How the tested configuration relates to the product in the quotation.

Avoid comparing bare numbers from different methods or units as if they were interchangeable. Where a tender specifies a particular method or scheme, send that requirement with the enquiry so the evidence can be checked against it. A general phrase such as “low VOC” is less useful than an identifiable document and a clear scope.

## A concrete Kermit technical-sheet example

The published [6 mm SPC technical data sheet, in Romanian](/downloads/technical-data-sheets/spc-flooring/kermit-spc-6mm-no-ixpe-tds-ro-2026-09.pdf) describes **6.00 mm total thickness, a 0.50 mm wear layer and no attached IXPE backing**. Those fields identify a particular configuration, not every Kermit floor.

The same sheet leaves acoustic performance undeclared for this configuration. You should not fill that gap with an impact-sound result from a product that has a different backing or test assembly. The [underlay and acoustics guide](/blog/spc-flooring-underlay-acoustics) explains which layers need to be specified together.

This is also why a fire classification, wear result and emissions assessment should remain separate entries in a project document schedule. Evidence for one property does not establish another, and evidence for flooring does not automatically cover a skirting profile or wall panel.

## Build a document schedule that can be checked

| Your project record | Information to keep |
| --- | --- |
| Ordered product | Collection, code, dimensions, thickness, wear layer and backing |
| Required property | The client's exact requirement and intended application |
| Evidence | File title, issuer, document number, version and date |
| Scope check | Product/holder/site coverage where specified, plus relevant annex |
| Status check | Current issuer listing or written clarification where needed |
| Acceptance | Reviewer, open questions and the decision before order approval |

For public Kermit files, use the [Resources library](/resources). For an additional certificate or laboratory report, [send the product code and project requirement](/contact) so the team can identify the applicable document. Request an accessible translation or explanation if you cannot evaluate the original language; retain the original alongside it.

If you are buying for your own brand, include the final brand name and packaging identification in the request. The [OEM guide](/blog/oem-private-label-spc-flooring) covers the rest of the brand-supply brief. A later change to backing, construction or product range should trigger another scope check rather than an automatic reuse of the previous file.

```faq
## Certificate and emissions questions

### Is a technical data sheet the same as an independent certificate?

No. A technical sheet records the manufacturer's product information. Independent certification has an issuing body, scheme and defined scope. Check which type of evidence your project needs.

### Does an ISO 9001 certificate prove a floor has low emissions?

No. ISO 9001 addresses quality management. Product emissions require the relevant product evidence and test or certification scope.

### Can one report cover every thickness and backing?

Only when the report or applicable certification scope actually includes them. Match the ordered configuration to the covered range and ask for clarification where the relationship is unclear.

### Where should I request documents for a Kermit order?

Start with the Resources library for published files. Send Kermit the selected product code, configuration, destination and required property for any additional evidence. Review the applicable document before treating a claim as confirmed.
```
