# SEO Rules for Blog Writing

Use for new articles, substantial rewrites, or edits affecting metadata and discovery.

## Metadata and keywords

Write specific, locale-natural titles, concise descriptions, and useful listing excerpts.
Match the topic's intent and use primary and secondary keywords where natural; avoid repeated
phrases added merely to satisfy placement counts. Use locale-specific tags that support
topical grouping. Required fields and allowed values are in `schema.md`.

## Internal links and next steps

Add internal links and CTAs where they help the reader continue the task described in the
section. Use specific link text and valid app paths. Avoid generic bottom "related page"
blocks or repeated sales copy; a few useful links are sufficient.

## Media and evidence

Use `media-workflow.md` when media changes: localized descriptions and relevant placements
support both accessibility and understanding. Use `claim-sources.md` for Kermit assertions,
and include the research and verification sources actually used in `sourceUrls`.

For FAQ sections, follow `docs/blog-authoring.md` so visible answers and generated schema
come from the same content.
